# গোলাপি ফাউন্ডেশন

- index.html — হোমপেজ
- apply.html — সহায়তার আবেদন ফর্ম
- admin.html — অ্যাডমিন প্যানেল (লগইন সুরক্ষিত)
- images/logo.webp — লোগো (আগে ৮ বার আলাদাভাবে base64 এমবেড করা ছিল, এখন একটাই শেয়ার্ড ফাইল)
- images/banner.webp — হিরো ব্যানার আর্ট (আগে বারবার এমবেড করা ছিল, এখন একটাই শেয়ার্ড ফাইল)

Firebase project: golapifoundation-84533

## এই আপডেটে যা ঠিক হয়েছে
আগের ভার্সনে লোগো ও ব্যানার ছবি সরাসরি প্রতিটা পেজের HTML কোডের ভেতরে (base64) বসানো ছিল —
একই ছবি হোমপেজে ৫ বার, মোট ৩ পেজ মিলিয়ে ৮ বার। এতে হোমপেজ একাই ছিল ৩৭৫KB।
এখন ছবি দুটো `images/` ফোল্ডারে আলাদা ফাইল হিসেবে আছে, আর সব পেজ সেটাকেই রেফারেন্স করে —
হোমপেজ এখন ~৪৬KB, আর ব্রাউজার ছবিগুলো একবার লোড করে সব পেজে ক্যাশ থেকে ব্যবহার করবে।

Netlify-এ deploy করলে এই ফোল্ডারের সবকিছু (images ফোল্ডারসহ) publish directory-তে থাকতে হবে।
